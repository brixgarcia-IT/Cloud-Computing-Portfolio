# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the major components of cloud infrastructure. The activity involves investigating a Linux cloud server, identifying compute, storage, networking, and operating system resources, comparing major cloud providers, and designing a simple cloud infrastructure.

## Objectives

- Explain the major components of cloud infrastructure.
- Investigate hardware and software resources in a Linux environment.
- Differentiate compute, storage, networking, and identity resources.
- Understand how cloud infrastructure components work together.
- Create technical documentation using Markdown.

## Cloud Infrastructure Components

The major components investigated in this laboratory are compute, storage, networking, and the operating system.
