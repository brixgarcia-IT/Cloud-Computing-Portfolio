# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure IAM | Cloud IAM |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, networking, databases, security, and many other areas. It is widely used by organizations with different types of cloud requirements.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

Microsoft Azure would be a good choice because it integrates closely with Microsoft products and services. This can make it easier for organizations already using Microsoft's technologies to manage their cloud environment.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its AI and machine learning capabilities and its strong support for Kubernetes. Google also created Kubernetes, which contributes to its strong position in container orchestration.

### 4. What similarities did you observe among the three cloud providers?

All three cloud providers offer compute, storage, networking, and identity and access management services. They provide similar types of infrastructure while using different service names and management tools.
