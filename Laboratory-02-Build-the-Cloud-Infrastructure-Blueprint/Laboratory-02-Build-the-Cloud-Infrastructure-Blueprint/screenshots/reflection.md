# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important components of cloud infrastructure because they provide the processing power needed to run applications and services. Without compute resources, cloud applications would not have the processing capacity needed to perform tasks.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable and flexible operating system for cloud servers. It allows administrators and cloud engineers to manage servers, execute commands, configure services, and monitor system resources.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it records the system configuration, resources, and design decisions before deployment. It helps engineers understand the planned infrastructure and can make troubleshooting and maintenance easier.

## 4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using terminal commands. I also learned how to identify compute, storage, networking, and operating system resources and document them using Markdown.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a structured laboratory project containing technical documentation, cloud infrastructure information, a provider comparison, screenshots, and an architecture diagram. This makes my portfolio more organized and demonstrates my cloud computing skills.
