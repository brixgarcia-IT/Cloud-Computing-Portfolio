Client A — Startup

Chosen Platform: Amazon Web Services (AWS)

AWS is a good choice because it offers flexible and scalable services that can help a startup control costs while its mobile application grows. AWS Lambda can run application code without managing servers, while Amazon DynamoDB provides scalable database storage and Amazon S3 can store files and images. AWS also supports mobile backends through services such as Amazon Cognito and AWS AppSync.

Client B — University

Chosen Platform: Microsoft Azure

Microsoft Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft identity and Windows environments, including Microsoft Entra services and Windows-compatible domain services.

Client C — AI Research

Chosen Platform: Google Cloud Platform (GCP)

Google Cloud Platform (GCP) is the best choice because it is strong in Artificial Intelligence, Machine Learning, and high-performance computing. Google Cloud provides AI/ML infrastructure and HPC resources using CPUs, GPUs, and optimized computing resources for demanding research workloads.

Client D — Global E-Commerce

Chosen Platform: Amazon Web Services (AWS)

AWS is an appropriate choice because its global infrastructure supports customers in different regions and provides multiple Availability Zones for high availability. AWS Auto Scaling can automatically adjust resources as traffic changes, while services such as Global Accelerator can route users toward healthy endpoints and support multi-region availability.
